# ERP_AMERICANA

Un simulador educativo que integra un ERP con CRM, el Ecommerce y la automatización de procesos.

## Qué hace el simulador

- El estudiante dirige una empresa colombiana durante 3 a 24 meses y decide precio, compras e importaciones (ERP), asesores y fidelización (CRM), pauta en Meta Ads y TikTok Ads (e-commerce), automatizaciones y crédito.
- Es configurable: empresa, nivel de dificultad, duración, mes de inicio, módulos que controla el estudiante y modo guiado.
- El docente comparte un código de partida para que todo el grupo enfrente el mismo mercado.
- Cada mes entrega retroalimentación pedagógica con el concepto clave. Al final genera una nota de 0,0 a 5,0, reflexión, evaluación tipo Saber Pro y evidencias en PDF, CSV y JSON.
- La narración por voz funciona en el navegador, sin servicios externos, con protecciones para que el audio no se corte ni se mezcle.
