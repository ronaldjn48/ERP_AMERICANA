# ERP_AMERICANA

Un simulador educativo que integra un ERP con CRM, el Ecommerce y la automatización de procesos.

## Qué hace el aplicativo

- Es una suite ERP educativa con barra lateral de módulos, buscador global, notificaciones y registros editables: CRM, ventas, comercio electrónico, inventario, compras, contabilidad con PUC, automatización y configuración.
- Cada acción genera sus movimientos de inventario y asientos contables de partida doble. El botón Cerrar día avanza el calendario y trae pedidos, cotizaciones, oportunidades, casos y pagos.
- Un centro de misiones gamificado guía la práctica en cada módulo: 20 misiones, preguntas de cálculo con datos propios, puntos de experiencia, 6 niveles y 10 insignias.
- El simulador gerencial de decisiones mensuales sigue disponible como módulo, con su informe, evaluación tipo Saber Pro y evidencias.
- El docente comparte un código de partida para que todo el grupo trabaje con la misma empresa, el mismo mercado y los mismos módulos.
- La narración por voz funciona en el navegador, sin servicios externos, con protecciones para que el audio no se corte ni se mezcle.
